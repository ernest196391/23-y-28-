# Fuente de verdad de assets — NO editar/regenerar

Sube aquí los dos archivos originales tal cual, sin recomprimir ni redibujar:

- `assets-source/veci-avatar-original.<ext>`  → Image A (avatar oficial de Veci)
- `assets-source/app-icon-original.<ext>`     → Image B (icono oficial de la app/PWA)

Usa la extensión real del archivo (png/jpg/webp). Una vez estén aquí, se generan
desde ellos (sin redibujar) los assets finales de producción:

- public/icons/icon-192.png
- public/icons/icon-512.png
- public/icons/maskable-icon-512.png
- public/apple-touch-icon.png
- public/brand/veci-avatar.png
