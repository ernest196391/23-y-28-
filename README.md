# Mercado 23 y 28
Aplicación web móvil del Mercado 23 y 28, Vedado, La Habana.

MVP de demostración con catálogo, búsqueda, carrito, fichas de productos y el asistente local Mercadito con entrada de voz. Los productos y precios permanecen identificados como demostración hasta recibir el inventario definitivo.
